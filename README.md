# White-label landing page prototypes

Three HTML/CSS-only hospitality landing-page concepts using the same fictional demo brief.

## Prototypes
1. `01-organic-natural/` — Organic / Natural
2. `02-cinematic-luxury/` — Cinematic Luxury
3. `03-neo-brutalist/` — Neo-Brutalist

## Run
Open any `index.html` file in a browser. No build step, framework, JavaScript, package manager, or server is required.

## Notes
- The business names, copy, email addresses, and locations are fictional demo content.
- Images are loaded from Unsplash URLs, so an internet connection is required for photography.
- Google Fonts are loaded remotely; system fallbacks are provided.
- Replace demo imagery, brand details, contact links, and copy before production.
- Each prototype has its own stylesheet and is independently editable.
